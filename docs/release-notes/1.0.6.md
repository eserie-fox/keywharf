# keywharf 1.0.6

`1.0.6` is a patch release that replaces the host-repository Git subprocess wrapper with GitPython while preserving the
existing clone-or-sync contract.

## Highlights

- Added the security-sensitive `GitPython>=3.1.59,<4` runtime dependency as a typed interface to system Git.
- Preserved clone into absent or empty targets, exact origin URL matching, and fast-forward-only updates.
- Added exact worktree-root validation and linked-worktree support.
- Preserved noninteractive HTTPS/SSH authentication behavior while relying on system credentials and SSH configuration.
- Sanitized expected Git failures and explicitly closed opened and cloned repository objects.

## Safety

Keywharf still never commits, pushes, stashes, resets, cleans, rewrites history, or changes remotes. GitPython does not
replace the system Git executable or the user's credential helpers, SSH agent, SSH configuration, or `known_hosts`.

## Upgrade note

No manager-config, host-repo, or state migration is required.
