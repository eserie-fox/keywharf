# keywharf 1.1.1

`1.1.1` is a patch release improving host discovery and privilege retries.

## Changes

- `select <query>` finds hosts by canonical name, declared alias, or endpoint hostname, ignoring
  case and outer query whitespace.
- Exact declared names take precedence over exact hostnames, followed by all substring matches.
  Ambiguous queries prompt in a terminal or fail with canonical candidates in scripts.
- Prefix matches share the substring tier, keeping other partial matches visible.
- Privilege retries preserve dash-prefixed queries and flag-like option values.

## Upgrade

No dependency, configuration, or state-schema changes are required. Selections retain canonical
identity and explicitly enabled SSH names. Finding a host by an alias does not enable that alias;
finding it by a hostname does not choose an endpoint. Existing endpoint/authentication selection
and render/apply behavior are preserved.
