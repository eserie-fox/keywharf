# keywharf 1.0.4

`1.0.4` is a release-closure patch focused on shipping the new high-frequency read-only convenience facade while keeping the canonical CLI command tree unchanged.

## Highlights

- Added four read-only convenience commands for frequent inspection: `keywharf list repo`, `keywharf show repo <server>`, `keywharf list local`, and `keywharf show local <server>`.
- Kept canonical paths as the primary interface: `keywharf repo host list/show` and `keywharf local list/show`.
- Kept convenience scope intentionally narrow: `repo` in this context means host definitions in the host repo, targets remain only `repo` and `local`, and there is no convenience facade for `endpoint`/`auth` or write-operation shortcuts.

## CLI Examples

```bash
# convenience read-only views
keywharf --workspace <path> list repo
keywharf --workspace <path> show repo <server>
keywharf --workspace <path> list local
keywharf --workspace <path> show local <server>

# canonical equivalents (still primary)
keywharf --workspace <path> repo host list
keywharf --workspace <path> repo host show <server>
keywharf --workspace <path> local list
keywharf --workspace <path> local show <server>
```

## Notable Changes

- Bumped runtime/package version metadata to `1.0.4` while keeping dynamic package version sourcing from `keywharf.version.__version__`.
- Added the `1.0.4` changelog entry and updated release-doc links to the latest release note.
- Aligned README and CLI docs with the convenience-versus-canonical relationship and explicit boundary wording.
- Added command-parity tests that verify convenience command behavior matches canonical command behavior.

## Upgrade Note

No breaking changes.

No config or state migration is required for existing workspaces.
