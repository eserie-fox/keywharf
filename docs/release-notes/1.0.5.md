# keywharf 1.0.5

`1.0.5` is a patch release focused on Typer/Click compatibility and release-readiness hygiene.

## Highlights

- Removed keywharf runtime imports of external `click`, avoiding startup failures in Typer versions that no longer install external Click as a dependency.
- Made canonical command retry reconstruction compatible with Typer-style parameter objects, including environments where Typer uses vendored Click internals.
- Preserved interactive `select` choice prompting while moving stream and prompt handling to Typer-facing APIs plus local range validation.
- Raised the runtime Typer baseline to `typer>=0.26` without importing external Click or Typer's private vendored Click API.

## Notable Changes

- Added invocation regression tests that exercise Typer-like arguments and options without relying on external Click classes.
- Added a dependency-scan test that checks direct runtime third-party imports against `pyproject.toml` runtime dependencies.
- Changed runtime dependency constraints to minimum-only policy: `jinja2>=3.1`, `pydantic>=2.7`, `rich>=13.8`, and `typer>=0.26`.
- Added explicit Ruff configuration for Python 3.11, 100-column formatting, import sorting, Python upgrade checks, Bugbear checks, and Ruff-specific checks.
- Raised dev dependency floors to `pytest>=8` and `ruff>=0.14` while keeping minimum-only dependency constraints.
- Fixed release-check blockers in the Python 3.11+ codebase so full Ruff format and lint validation can pass.
- Bumped runtime/package version metadata to `1.0.5` while keeping dynamic package version sourcing from `keywharf.version.__version__`.

## Upgrade Note

No breaking changes.

No config or state migration is required for existing workspaces.
