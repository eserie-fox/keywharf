# keywharf 1.0.3

`1.0.3` aligns the release with the current `select` behavior, cleans up expected CLI error output, and finishes the related documentation and version metadata updates.

## Highlights

- `select` now prompts in interactive terminals when a host has multiple endpoint or authentication choices and you omit `--endpoint` or `--auth`.
- Noninteractive `select` usage still requires explicit stable names when multiple choices exist.
- Expected `KeywharfError` exits now print cleanly without the extra `click.exceptions.Exit` traceback.
- README, CLI, and configuration docs now match the current selection and local-state semantics.

## Notable Changes

- Bumped the runtime/package version to `1.0.3`.
- Added the `1.0.3` changelog entry and release note.
- Added a small `docs/release.md` entrypoint that links the canonical changelog and current release note.

## Upgrade Note

No config or state migration is required for existing workspaces.
